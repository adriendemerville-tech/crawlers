## 0. Verdict

Le socle **déclaratif** (score GEO on-page + visibilité LLM) fonctionne et coûte peu. Les deux couches qui constituent notre différenciateur annoncé — **preuve technique (bots IA vérifiés)** et **impact business (attribution)** — sont **vides en production** : 0 bot hit, 0 événement d'attribution, 0 Shield actif, 0 snapshot de visibilité, KPIs figés depuis le 2026-05-08. La promesse « visibilité déclarée + preuve + attribution + correction » n'est aujourd'hui tenue que sur le premier tiers, et aucun constat GEO n'atteint le Workbench, donc Parménion ne corrige rien côté GEO.

## 4. Ce qui est bien / insuffisant / trompeur / manquant

- **Bien** : `check-geo` déterministe et sans coût LLM (rare sur le marché, tous nos concurrents facturent du prompt) ; traçabilité textuelle systématique des citations ; crons découplés ; attribution codée proprement (fenêtre 30 j + `exp(-d/15)`).
- **Insuffisant** : logging de coût partiel ; tooltips méthodologiques incomplets ; modèles figés dans le code au lieu du routeur.
- **Trompeur** : un modèle en erreur affiché comme « ne cite pas la marque » (H1) ; cartes Shield / Crawl / Attribution rendues alors qu'aucune donnée n'a jamais existé, ce qui suggère « 0 crawl IA » au lieu de « non mesuré ».
- **Manquant** : passerelle vers le Workbench (H2), skill Copilot GEO (H7), onboarding Shield réellement conclu (H4).

## 5. Plan de correction proposé

**P0**
1. `calculate-llm-visibility` : distinguer `not_cited` de `error` / `timeout` — nouveau statut d'exécution, exclusion des modèles en erreur du dénominateur, affichage « n modèles non mesurés » côté UI.
2. Écrire les constats GEO dans `architect_workbench` (`source_type = 'geo_audit'`) : score < seuil, `llms.txt` absent, JSON-LD manquant, passages non citables, robots.txt bloquant un bot IA — avec cooldown pour éviter les doublons.

**P1**
3. Router `detect-fan-out` et `snapshot-geo-visibility` via `_shared/aiRouter.ts` / `aiGatewayFetch` + `trackTokenUsage`.
4. Rendre l'état « non mesuré » explicite : cartes Shield / Crawl / Attribution en état vide pédagogique + CTA d'installation, jamais de « 0 » présenté comme un résultat.

**P2**
5. Modèles depuis le routeur + suppression des `any` résiduels.
6. `MethodologyTooltip` sur les 5 cartes manquantes.
7. Skill Copilot `audit_geo` (lecture score + fan-out + KPIs, sans écriture).
