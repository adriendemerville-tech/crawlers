# Audit Brief — Cocoon / Stratège
Date : 2026-08-10 · Auditeur : Lovable · Baseline : `knowledge/audits/cocoon/brief-2026-07-08.md` (audit #4 du programme 11 outils ; les 3 précédents — Audit Stratégique IA, Crawl multi-pages, GEO/LLM Visibility — sont soldés)

## 1. Objectif métier
Donner à l'utilisateur une lecture actionnable de l'architecture sémantique de son site (clusters, profondeur, cannibalisation, pages orphelines) puis prescrire et déployer le maillage interne et le plan éditorial correspondant, sans intervention manuelle.

Domaines témoins : `iktracker.fr` (site autopiloté, historique de cycles Parménion) et `avenir-renovations.fr` (gros site multi-agences, ~7 000 URLs, sert de test de charge).

## 2. Cas d'usage principaux
- **Premium** → sélectionne un site → visualise le cocon (2D / 3D / radial) → identifie clusters faibles et cannibalisation
- **Premium** → chat Stratège sur nodes sélectionnés → obtient un diagnostic + 3 réponses proposées en boutons
- **Pro Agency** → `plan_editorial` → plan de 8 tâches typées persistées → Plan de tâches
- **Pro Agency** → `deploy_cocoon_plan` (approbation) → injection des liens 3 tiers → push CMS
- **Parménion** → consomme `cocoon-strategist` en mode déterministe pour prescrire son cycle
- **Cron hebdo** → `cron-cocoon-refresh` recalcule les liens auto sur les sites opt-in

## 3. Logique métier clé
- Comprehensive engine v3 : clusters, cannibalisation, saturation (mem `cocoon/comprehensive-engine-v3-fr`)
- Depth logic : BFS ↔ impact stratégie (mem `cocoon/depth-logic-fr`)
- Page intent Know/Do/Buy/Navigate/Unknown, confidence < 0.7 → unknown (mem `page-intent-and-mesh-audit-fr`)
- Anti-cannibalisation + saturation guard (mem `anti-cannibalization-logic-fr`, `dedup-synonym-layer-fr`)
- Content Integrity (SimHash/LSH, seuil 30 pages comparables sinon inconclusive)
- Plafonds grands sites : 10 000 pages, similarité par index inversé > 400 docs, rendu 3D plafonné 1 500 nœuds (mem `large-site-scaling-fr`)
- Skills Copilot Stratège : `analyze_cocoon`, `plan_editorial` (auto), `deploy_cocoon_plan` (approval)
- Gating : Premium pour visualisation + chat, Pro Agency pour bulk/deploy
- Dépendances : `cocoon-strategist` (1 775 l.), `calculate-cocoon-logic` (843 l.), `cocoon-chat` (601 l.), 5 `cocoon-diag-*`, `cocoon-auto-linking` / `bulk-auto-linking` / `deploy-links` / `batch-deploy`, `persist-cocoon-session`, `cron-cocoon-refresh`
- Consommateurs amont/aval : `parmenion-orchestrator`, `copilot-orchestrator/skills/registry.ts`, `audit-strategique-ia`, `architect_workbench`

## 4. Critères de qualité attendus
| Axe | Cible | Mesure |
|---|---|---|
| Fonctionnel | diagnostic non vide sur les 2 domaines témoins ; 0 recommandation dupliquée ; liens déployés vérifiables en HTML | exécution réelle + requêtes SQL |
| Fiabilité des chiffres | aucun score calculé sur un échantillon insuffisant sans mention explicite (parité avec la règle 30 pages du Content Integrity) | lecture code + sorties |
| Boucle mesure → correction | tout finding cocoon critique atterrit dans `architect_workbench` et est consommable par Parménion | SQL sur `architect_workbench` |
| Performance | plan sur site 7 000 URLs sans timeout ; rendu graphe fluide jusqu'à 1 500 nœuds | logs edge + Profiler |
| Coût LLM | < 2¢ / message chat, < 8¢ / plan éditorial, 100 % des appels loggés dans `ai_gateway_usage` | `ai_gateway_usage` |
| Sécurité | RLS + GRANT, isolation `auth.uid()`, ownership vérifié avant toute injection/déploiement | `security--run_security_scan` + lecture policies |
| UX | design system Crawlers (violet / or / noir / blanc), pas d'emoji, pas de bleu IA, boutons bordure + texte | revue visuelle |

## 5. Benchmark concurrentiel
| Concurrent | Force | Faiblesse vs Cocoon |
|---|---|---|
| **Cocoon.se (Laurent Bourrelly)** | Méthodologie de référence du cocon sémantique FR | Manuel, zéro visualisation, zéro exécution |
| **Screaming Frog + Sitebulb** | Crawl fiable, PageRank interne, rapports détaillés | Rapport statique, aucune prescription, aucun déploiement |
| **Ahrefs Internal Links / Site Structure** | Données fraîches, score d'autorité interne | Vue tabulaire, pas de clusters sémantiques, pas d'agent |
| **Babbar.tech (semantic value / induced strength)** | Le plus proche sur la sémantique de maillage, métriques propriétaires solides | Pas de plan éditorial, pas de push CMS, pas de chat contextuel |
| **Haloscan** | Bon rapport prix/données FR, cannibalisation SERP | Cannibalisation vue SERP seulement, pas de graphe ni d'exécution |
| **Neuronwriter / Thot SEO** | Recommandations sémantiques par page | One-shot, pas de vue site, pas de déploiement |

**Barre à atteindre / dépasser** : ne pas chercher à battre Babbar sur la métrique de valeur sémantique brute. Rester le seul à fermer la boucle **diagnostic graphe → prescription typée → déploiement des liens en production → re-mesure**. Angle mort à vérifier : les concurrents exposent leurs données via API/MCP, Cocoon doit être consommable de la même façon.
