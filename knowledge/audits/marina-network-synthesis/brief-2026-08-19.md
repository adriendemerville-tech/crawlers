# Audit Brief — Synthèse réseau des audits Marina multipages
Date : 2026-08-19 · Auditeur : Lovable · Baseline : première itération (module livré ce jour, trous 1 à 10 traités)

## 1. Objectif métier
Tout rapport Marina multipages doit s'ouvrir sur une lecture d'ensemble déterministe, honnête et séquencée du lot audité (ce que les pages décrivent ensemble, comment elles s'organisent, ce qu'il faut corriger dans quel ordre), puis archiver ces constats et les transformer en tâches de travail exploitables.

## 2. Cas d'usage principaux
- Free / one-shot → lance un audit multipages depuis `/marina` → le PDF consolidé s'ouvre sur les 8 blocs de synthèse avant les rapports page par page.
- Premium / Pro Agency → reconstruit un export depuis « Mes audits » → même synthèse, calculée sur les rapports déjà stockés.
- Pro Agency → après export → retrouve les actions de réseau dans le plan de travail (Workbench), sans ressaisie.
- Admin → compare deux lots du même domaine dans le temps via les instantanés archivés.

## 3. Logique métier clé
- Séquence invariante en 8 blocs : périmètre & données, matrice de gabarits, écart technique/sémantique, concurrence interne, audit de hiérarchie, maillon faible, plan séquencé, contrat de lecture.
- Régime de cohésion : `reseau` / `arborescence` / `assemblage` / `mixte` (35-60 % d'URLs déclinées → deux sous-lots nommés, les lectures de réseau ne portent que sur le noyau).
- Garde-fous d'effectif : solidité `fragile` (<3) / `indicatif` (<5) / `solide` (>=5) ; couverture métrique affichée en fraction, moyenne marquée « partielle » sous 50 %.
- Priorisation sans constantes magiques : `gravité mesurée × portée dans le lot × confiance × facilité`, confiance = mesuré 1 / déduit 0,85 / estimé 0,6 pondérée par la solidité.
- Lot propre : bascule sur des actions de développement marquées « Estimé », jamais en sévérité critique.
- Gabarits confirmés par le contenu : scission d'un gabarit >=4 pages dont les clusters forment deux groupes nets.
- Dépendances : tables `marina_network_syntheses`, `architect_workbench` (index unique `(source_type, source_record_id)`), `crawl_pages` / `site_crawls` (contexte de structure), `marina_prospects` (rapports sources) ; pas d'appel LLM dans ce module (100 % déterministe).
- Contraintes projet : violet/or/noir/blanc, aucun emoji, pas de bleu IA, boutons bordure + texte ; isolation `auth.uid()` ; provenance Mesuré/Testé/Déduit/Estimé obligatoire.
- Mémoires applicables : mem://features/marina/multipage-mutualization-and-disclosure-fr, mem://tech/security/multi-tenant-isolation-fr, mem://tech/architect/shared-workbench-v2-fr, mem://tech/audit/main-strategic-path-fr.

## 5. Benchmark concurrentiel
- Semrush Site Audit : agrège des erreurs par volume mais ne produit aucune lecture d'ensemble de ce que les pages décrivent ; force = exhaustivité technique, faiblesse = zéro hiérarchie éditoriale.
- Screaming Frog : cartographie le maillage réellement mesuré (force), aucune conclusion ni priorisation (faiblesse).
- Ahrefs Site Structure : bons regroupements par répertoire, pas de verdict pilier/satellite ni de plan séquencé.
- Barre à atteindre : livrer ce qu'aucun d'eux ne fait — une conclusion nommée, séquencée, avec niveau de preuve par constat, et sans jamais inventer un chiffre. TODO utilisateur : corriger/compléter cette liste (marché FR).
